〇、先说三件事

这份题集只覆盖期末会考的基础语法，不含算法设计大题。做题方式：先自己写，写不出再看答案，答案都在每题下方折叠区里。全部代码用 gcc -std=c99 -Wall 编译通过，零警告。

一、变量与输入输出（题 1-8）

这一组解决三件事：变量怎么声明、printf/scanf 的格式串、整数与浮点的坑。先看一个最小可运行程序：

#include <stdio.h>
int main(void) {
    int n, sum = 0;
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) sum += i;
    printf("%d\n", sum);
    return 0;
}

题 3 是这组里最容易错的：int 相除会截断小数，3/2 得 1 而不是 1.5。要小数先转 double，或者写成 3/2.0。

二、分支（题 9-14）

switch 的 case 只能放整型常量，漏 break 会穿到底——期末每年都考这两点。题 12 的分段函数是经典题：先用 if-else 写一遍，再用 switch 配整除技巧写一遍，对比着记。

if (score >= 90) grade = 'A';
else if (score >= 80) grade = 'B';
else if (score >= 60) grade = 'C';
else grade = 'F';

三、循环（题 15-22）

循环题的通解：先想清楚「循环不变量」——每轮结束时什么是对的。题 18 的斐波那契、题 20 的质数判断、题 22 的九九乘法表，全部只用一层或两层 for 就能写完。

四到十二、数组 / 函数 / 指针 / 字符串 / 结构体 / 文件（题 23-58）

指针是重头：& 取地址、* 解引用、数组名在表达式里退化为首地址。题 41「用指针交换两个变量」和题 45「指针遍历数组」吃透，后面链表题才有底。结构体重点考 struct 定义、成员访问（. 与 -> 的区别）、结构体数组排序。

十三、综合题（题 59-66）

八道小综合：学生成绩管理、简易计算器、字符串统计、二分查找、冒泡排序、链表反转、文件读写抄录、综合调试题。每题都给完整可编译代码和逐行讲解，做完这一组，期末编程大题的骨架就有了。
